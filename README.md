Задание 20.2.1 (PJ-04)
Напишите код, реализующий пайплайн, работающий с целыми числами и состоящий из следующих стадий:

Стадия фильтрации отрицательных чисел (не пропускать отрицательные числа).
Стадия фильтрации чисел, не кратных 3 (не пропускать такие числа), исключая также и 0.
Стадия буферизации данных в кольцевом буфере с интерфейсом, соответствующим тому, который был дан в качестве задания в 19 модуле. 
В этой стадии предусмотреть опустошение буфера (и соответственно, передачу этих данных, если они есть, дальше) 
с определённым интервалом во времени. Значения размера буфера и этого интервала времени сделать настраиваемыми.

Реализация состоит из двух частей:
1. модуль data-source - реализует отправку данных в сокет. Данные представляют собой случайные числа от -1000 до 1000,
а также не числовые данные 

2. модуль data-handler - реализует пайплайн из стадий получения данных из сокета,  фильтрации данных, 
помещения отфильтрованных данных в кольцевой буфер и вывода данных в консоль. 

3. Взаимодействие контейнеров реализовано при помощи docker сети. 

4. Запуск контейнеров (Docker Compose version v5.1.4) осуществляется коммандой ```sudo docker compose up```
